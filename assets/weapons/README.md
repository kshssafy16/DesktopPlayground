# Gun 게임용 에셋 가이드

무기 그림을 사용하려면 `assets/weapons/`에 아래 파일을 저장하고 앱에서 참조하세요.

- `awm.png`: 오른쪽을 향한 AWM 계열 게임용 저격총 그림
- `ak47.png`: 오른쪽을 향한 AK 계열 게임용 라이플 그림
- `uzi.png`: 오른쪽을 향한 UZI 계열 기관단총 그림
- `double_barrel.png`: 오른쪽을 향한 더블배럴 샷건 그림

권장 형식: 투명 배경 RGBA PNG, 무기 전체가 보이는 형태. 크기가 달라도 일정한 게임 내 표시 높이와 총구 앵커(`muzzle`)로 정규화합니다. 총구 기준점이 마우스 레드도트 방향에 맞도록 하고, 총기 그림이 조준점을 가리지 않게 배치합니다. 이미지 원본을 잘라서 잘림을 숨기지 않습니다.

별도 이미지가 없을 경우에는 임시로 Canvas에 네 무기의 고유 실루엣을 그려도 됩니다. 파란 막대 한 종류를 네 무기에 공통 사용하지 마세요.

이 파일들은 무기를 실제 사용하는 방법이 아니라 애플리케이션의 비살상 장난감 그래픽과 UI 구현을 위한 자산입니다. 외부 이미지 검색 결과의 저작물을 라이선스 확인 없이 공개 빌드에 포함하지 않습니다.
