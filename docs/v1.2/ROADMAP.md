# DesktopPlayground 차기 개발 로드맵

기준 릴리스: `v1.1.0` (2026-10-15 검토 기준). 본 문서는 v1.1 개발 기록을 대체하지 않고 차기 계획만 추가한다.

## 제품 목표

- 방치형 귀여움과 스트레스 해소, 사용 중인 다른 앱을 방해하지 않는 입력 처리가 우선.
- 기존 v1.1 기능, 오프라인 실행, Windows x64 portable, 기존 사용자 설정 보존.
- 사용자 검증 중심의 작은 구현 단위, 과도한 자동 시뮬레이션/렌더 캡처 금지.
- 펫 생성 무제한 정책 유지. 성능을 이유로 개별 펫을 몰래 삭제하지 않는다.

## 확정 정책

- 블랙홀은 기존처럼 흡입 후 **해당 인스턴스만 삭제**. 10개 상한. 11번째 생성 시 가장 오래된 홀을 **안전하게 종료/교체**하는 후보를 유지하되 실제 코드 상태를 먼저 검사하고 orbit 해제 뒤 처리.
- v1.1 도구 Gun 4종/수류탄/망치/Draw, 비살상 피격, 상단 개방, 수면 5~60분, 작업표시줄 범위 및 툴바 숨기기 보존.
- 페트 인스턴스의 **생성에는 하드 상한 없음**.
- 앱의 기존 renderer/IPC/Tray 보안 설정 보존. userData 경로 `%APPDATA%/desktop-playground` 유지.
- 시작 펫 4종 유지: 슬라임, 황색냥, 시바, 커비.
- 기존 9종 프로필 유지. 신규 이미지가 없으면 없는 그림을 가정하지 않는다.
- 펫 간 물리 충돌 없음. 사용자 Throw와 외부 Hit은 바운스, 자율 점프는 무반발.
- Phase 전환 시 사용자 수동 QA를 우선하고, 검증되지 않은 결과를 통과로 적지 않음.

## 작업 우선순위 결정

- 사용성과 범위가 큰 `v1.2`(블랙홀/툴바/펫 관리)를 먼저 배포.
- 신규 에셋 제작, 로컬 import 보안과 구조물 디자인은 `v1.3`으로 분리해 통합 위험과 모델 사용량을 제한.
- 기존 문서의 오래된 'Gun 사망/KO', 'Bomb 즉시 폭발', '2개만 허용' 등의 기록을 현재 동작으로 오인하지 않음.
- README가 v1.0.0 링크와 구형 기능을 설명하므로 다음 배포 전에 현재 릴리스 기준으로 업데이트.
- **공개 GitHub에 이미 포함된 제3자 자산의 재배포 권한 미확인** 문제를 별도 점검. 개인 사용 의도만으로 재배포 허가가 생기지 않음. v1.2 공개 산출물에 신규 유명 캐릭터를 넣지 않음.
- Electron 29 기반의 오래된 의존성 교체/보안 갱신은 새 기능과 혼합하지 말고 별도 호환성 작업으로 계획. 최신 버전 판단은 작업 시 공식 릴리스/변경 로그 확인.
