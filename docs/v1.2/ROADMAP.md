# DesktopPlayground 차기 개발 로드맵

기준 릴리스: `v1.1.0` (2026-10-15 검토 기준). 본 문서는 v1.1 개발 기록을 대체하지 않고 차기 계획만 추가한다.

## 현재 작업 트리 상태 (2026-10-15)

`feature/v1.2`의 변경은 미커밋·미빌드 상태이며 `package.json` 버전도 아직 `1.1.0`이다. 아래의 완료는 **코드 구현**을 뜻하고, v1.2 배포 승인이나 전체 Windows 수동 검수 완료를 뜻하지 않는다.

| 범위 | 현재 구현 | 확인 상태 |
| --- | --- | --- |
| Phase 3-D | 블랙홀 최대 10개, 11번째의 오래된 홀 교체와 orbit/Grab 참조 정리 | 핵심 자동 테스트 통과; 실제 10개 동시 사용·다중 화면 확인 남음 |
| Phase 4-A와 조작 피드백 | 시작 펫 3종, 9버튼 툴바·놀이/펫/그리기 메뉴, PC 클릭 통과, 전체 숨김과 툴바만 숨김, 툴바 드래그·Tray 복원, 도구별 커서 | 시작/입력 smoke 통과; 작업 표시줄 색·창 순서·DPI·마우스 조작 확인 남음 |
| Phase 4-B | 현재 펫을 종류별 마릿수로 보여주고 3종씩 페이지 이동; `삭제`는 확인창 없이 해당 종류의 인스턴스만 제거. Trash 개별 삭제는 유지 | 관리 핵심 테스트 통과; 실제 메뉴 가독성·삭제 흐름 확인 남음 |
| 후속 장난감 피드백 | 허공 Gun의 무기별 화면 파손, Hammer 국소 균열·초기화, Gun/Hammer/Bomb 명중 콤보, 수류탄 Draw 충돌, 수동 소환 때 드문 보스(종류별 HP·막대만 표시·수면 자세 페이드) | 핵심 자동 테스트 통과; 사용자 확인: 보스 생성/피해와 수류탄 충돌 정상. 최신 체력바·콤보 크기/페이드는 화면 확인 남음 |
| 신규 로컬 펫 2종 | 콜덕·아기 하프물범의 제공 ZIP 자산과 애니메이션 프로필을 카탈로그·펫 메뉴·공통 관리 경로에 통합 | 구조/상태 핵심 검사 통과; 실제 Windows 보행·발 위치·상호작용 화면 확인 남음 |

마감 전 소규모 보완: 실제 Sleep의 작은 `z` 표시, 콤보 단계별 약한 강조와 짧은 페이드, 보스 등장·처치 표시를 추가했다. 요청되지 않은 quit은 로그를 남기고 차단하지만, 약 3분 후 종료 신고의 실제 원인은 미확정이므로 Windows 장시간 확인이 남는다.

**v1.2 마감 전 남은 일:** 실제 Windows에서 작업 표시줄 밝기·클릭 통과/창 순서, 툴바·팝업/커서, 장시간 실행(약 3분 후 예기치 않은 종료 신고는 1회 재현 실패), 보스 막대와 콤보 표시를 확인한다. 이전 전체 smoke에서 기록된 우사기/푸들 Sleep 발 위치와 native window-order 작업 표시줄 판정 실패는 독립 재검토가 필요하다. 그 뒤 전체 회귀·권리 점검, README/릴리스 노트·버전·패키징을 처리한다. 현재는 빌드·커밋·Push·배포를 하지 않았다. 세부 수동 항목은 [QA](QA_CHECKLIST.md), 변경 경위는 [결정 기록](DECISIONS_AND_PROGRESS.md)에 있다.

**다음 버전으로 분리:** 임의의 로컬 펫 패키지 가져오기, 나머지 신규 오리지널 펫, 구조물 디자인, 캐릭터 스킬, 광범위 성능/의존성 갱신. 이번 두 ZIP만 선택적으로 앱에 적용했으며 애니메이션 담당 브랜치 전체를 병합한 것은 아니다.

## 제품 목표

- 방치형 귀여움과 스트레스 해소, 사용 중인 다른 앱을 방해하지 않는 입력 처리가 우선.
- 기존 v1.1 기능, 오프라인 실행, Windows x64 portable, 기존 사용자 설정 보존.
- 사용자 검증 중심의 작은 구현 단위, 과도한 자동 시뮬레이션/렌더 캡처 금지.
- 펫 생성 무제한 정책 유지. 성능을 이유로 개별 펫을 몰래 삭제하지 않는다.

## 확정 정책

- 블랙홀은 기존처럼 흡입 후 **해당 인스턴스만 삭제**. 10개 상한. 11번째 생성 시 가장 오래된 홀을 교체하고 관련 orbit·Grab 구출 참조를 해제한다.
- Phase 3-D 구현: 11번째 홀 생성 시 기존 `pruneBlackHoleReferences`로 교체된 홀의 orbit·Grab 구출 제외 ID를 즉시 해제한다. 만료·효과 삭제도 같은 정리를 사용한다. 범위 밖 펫은 제곱 거리로 먼저 제외하고, 홀 만료가 없으면 매 프레임 전체 펫 참조 정리를 반복하지 않는다. 자세한 검증은 [진행 기록](DECISIONS_AND_PROGRESS.md)에 남긴다.
- v1.1 도구 Gun 4종/수류탄/망치/Draw, 비살상 피격, 상단 개방, 수면 5~60분, 작업표시줄 범위 및 툴바 숨기기 보존.
- 페트 인스턴스의 **생성에는 하드 상한 없음**.
- 앱의 기존 renderer/IPC/Tray 보안 설정 보존. userData 경로 `%APPDATA%/desktop-playground` 유지.
- 시작 펫 3종: 커비, 황색냥, 시바. 슬라임은 펫 메뉴에서 계속 수동 추가할 수 있다(2026-10-15 사용자 변경).
- Phase 4-A 수동 피드백: PC 모드에서도 작업 표시줄 위 펫 픽셀을 유지하면서 클릭은 통과시킨다. 도구 모드는 전체 화면 입력을 소비한다. 더보기 없는 9버튼 툴바와 스크롤 없는 메뉴는 코드 수정 후 사용자 Windows 검수 대기. [진행 기록](DECISIONS_AND_PROGRESS.md) 참조.
- 기존 9종 프로필 유지. 신규 이미지가 없으면 없는 그림을 가정하지 않는다.
- 펫 간 물리 충돌 없음. 사용자 Throw와 외부 Hit은 바운스, 자율 점프는 무반발.
- Phase 전환 시 사용자 수동 QA를 우선하고, 검증되지 않은 결과를 통과로 적지 않음.

## 작업 우선순위 결정

- 사용성과 범위가 큰 `v1.2`(블랙홀/툴바/펫 관리)를 먼저 배포.
- 신규 에셋 제작, 로컬 import 보안과 구조물 디자인은 `v1.3`으로 분리해 통합 위험과 모델 사용량을 제한.
- 기존 문서의 오래된 'Gun 사망/KO', 'Bomb 즉시 폭발', '2개만 허용' 등의 기록을 현재 동작으로 오인하지 않음.
- README가 v1.0.0 링크와 구형 기능을 설명하므로 다음 배포 전에 현재 릴리스 기준으로 업데이트.
- **공개 GitHub에 이미 포함된 제3자 자산의 재배포 권한 미확인** 문제를 별도 점검. 개인 사용 의도만으로 재배포 허가가 생기지 않음. v1.2 공개 산출물에 신규 유명 캐릭터를 넣지 않음.
- Electron 29 기반의 오래된 의존성 교체/보안 갱신은 새 기능과 혼합하지 말고 별도 호환성 작업으로 계획. 최신 버전 판단은 작업 시 공식 릴리스/변경 로그 확인.
