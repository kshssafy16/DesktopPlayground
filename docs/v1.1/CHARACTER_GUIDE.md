# v1.1 캐릭터와 그래픽 제작 가이드

목적: 먼저 펫별 특성과 그래픽 규격을 정하고, 실제 이미지는 별도로 제작한 후 코드에 연결한다. **이 문서에 적힌 신규 이미지는 아직 제작되지 않았다.**

## 1. 기존 펫 유지 정책

- 시작 4개: `blob` 슬라임, `cat_brown` 황색냥, `doge` 시바, `kirby` 커비.
- 내장 Canvas 기본 선택지는 `blob` 슬라임만 남긴다. 로봇, 유령, 별, 구름은 UI에서 제거한다. 사용 안 한다는 이유만으로 관련 정의나 파일을 위험하게 즉시 삭제하지 않는다.
- Sprite 고양이: `cat_brown`, `cat_face`, `cat_sleepy`, `salary-cat`.
- Sprite 강아지: `doge`, `puddle` (표시 이름 푸들).
- Sprite 캐릭터: `usagi`, `kirby`, `kirby_sleepy`.
- 숨긴 옛 기본 Cat, Magpie 등 legacy 참조/이미지 제거는 코드 점검과 회귀 검사 이후로 미룬다.

## 2. 실제 품질 검사

기존 및 신규 스프라이트마다 다음을 확인한다.

1. `pet.json`의 ID, 이름, sheet 경로, 실제 WebP 가로/세로, 행/열 수가 일치하는가.
2. 현재 로더가 사용하는 8열 9행/11행 규격과 실제 각 행의 자세가 일치하는가.
3. walk/idle/fall/drag 클립이 비어 있거나 엉뚱한 표정이 섞이지 않는가.
4. 패딩, 발 위치, render anchor, 캐릭터 크기, 방향 반전이 자연스러운가.
5. 점프/던지기/착지 squash 후 캐릭터가 과도하게 늘어나거나 깨지지 않는가.
6. Sleepy/Salary 등 소품을 가진 펫의 소품이 부자연스럽게 뒤집히지 않는가.
7. 원본 WebP는 변경 전 백업하거나 Git diff로 복원할 수 있게 한다. 이미지 수정 전후 프레임을 확인한다.
8. 시트와 로더 변경이 `tests/local-pets.cjs` 및 startup smoke에 영향을 주는지 확인한다.

고칠 수 있는 범위: clip mapping, 프레임 속도, anchor, 투명 여백과 크기 보정, 필요한 경우 손상된 프레임 교체. 단 기존에 정상인 다른 펫의 이미지와 동작은 보존한다.

## 3. 캐릭터별 추천 활동성

| ID 또는 타입 | 대기/휴식 경향 | 이동/점프 경향 | 연출 우선 포인트 |
| --- | --- | --- | --- |
| blob | 중간 | 중간 | 형태 squash, 말랑한 착지 |
| cat_brown | 높음 | 낮음 | 휴식, 눈 깜박임, 느긋함 |
| cat_face | 중간 | 중간 | 표정 강조, 짧은 움직임 |
| cat_sleepy | 매우 높음 | 매우 낮음 | 충분히 오래 자는 모습 |
| salary-cat | 높음 | 낮음 | 소품/직장인 캐릭터성 |
| doge | 중간 | 높음 | 뛸 때 귀와 몸이 반응 |
| puddle | 중간 | 중간 | Phase 2-A 최신 요청: 보통 활동성, 발걸음·반응·소품 |
| usagi | 낮음 | 매우 높음 | 활발한 점프, 잠깐 바라보기 |

프로필 값은 실제 관찰로 조정한다. 활동성은 속도만 빠르게 만드는 것이 아니라 상태 빈도, 이동 거리, 점프 확률, 쉬는 시간의 조합이다.

## 4. 신규 오리지널 5종

아래 캐릭터는 향후 이 채팅에서 디자인과 스프라이트를 제작할 수 있는 기획이다. 기존 유명 캐릭터의 모양과 로고를 복제하지 않는다.

### 말티즈

- 작은 흰 강아지, 둥글고 부드러운 눈매, 귀끝과 짧은 다리.
- 그림체: 과하게 세밀하지 않은 부드러운 2D 마스코트.
- 성격: 호기심이 많고 기분 좋게 짧게 뛰어다님.
- 우선 모션: idle, walk L/R, jump, fall, drag/scared, hit/knockout.

### 포메라니안

- 크림/살구색의 폭신한 털 실루엣, 작은 귀, 통통한 몸통.
- 성격: 활발하지만 짧게 쉬는 행동이 잦음.
- 우선 모션: idle, walk L/R, hop, fall, drag, hit/knockout. 빠른 꼬리 움직임은 선택.

### 웰시코기

- 짧은 다리와 길쭉한 몸, 큰 귀, 따뜻한 브라운/화이트.
- 성격: 기운찬 이동과 바닥에서 굴러가는 모습.
- 우선 모션: idle, walk L/R, jump, fall, drag, hit/knockout.

### 오리

- 작은 노란 오리, 솜털 표현은 단순하게, 둥근 머리와 작은 부리.
- 이름은 `오리`로 확정. `솜털오리`는 표시 이름으로 사용하지 않는다.
- 성격: 뒤뚱거리며 가끔 날갯짓, 놀라면 잠깐 굳음.
- 우선 모션: idle, waddle L/R, small hop, fall, drag, hit/knockout.

### 하프물범

- 흰 아기 물범의 둥근 실루엣, 검은 눈과 코, 작은 지느러미.
- 성격: 오래 휴식, 배로 미끄러지는 낮고 천천한 이동.
- 우선 모션: idle, slide L/R, short hop, fall, drag, hit/knockout.

## 5. 신규 그래픽 공통 산출물

- 각 캐릭터의 정면/측면 및 2~4개 감정 표정 시안부터 확정.
- 확정한 디자인의 일관된 sprite sheet를 제작. 행/열과 frame 의미는 `pet.json` 또는 향후 앱 전용 metadata에 명시.
- 같은 프레임 안에 동일 크기, 앵커, 기준선, 배경 투명을 유지.
- 작은 크기(예: 48~80px 정도)에 렌더했을 때 표정과 형태가 보여야 함.
- 원본 디자인 파일은 앱 밖의 작업용 저장소에 보관하고, 배포용은 필요한 이미지와 metadata만 포함.
- 조작 도구의 이펙트와 색 대비를 고려해 너무 밝거나 지나치게 채도 높은 디자인을 피한다.

## 6. 개인용 유명 캐릭터

커비, 우사기 등 기존 로컬 펫 및 추후 파닥몬, 테리어몬, 치이카와, 쿠리만쥬, 우소우소 등의 개인용 패키지는 공개 배포 자산과 분리한다. 사용자가 개인적으로 가져오는 흐름을 우선 지원한다. GitHub에 포함된 이미지의 공개 재배포 권한은 개인 사용 계획과 별개로 확인 대상이다.

캐릭터 추가 과정에서 시스템 전체 Pet 클래스에 특정 캐릭터 하드코딩을 늘리지 않고 definition과 성격 preset, animation clip metadata로 연결한다.

Jump/Fall은 loop:false로 마지막 프레임을 유지해 공중에서 발사·착지 자세를 반복하지 않는다. 드래그에서 크게 누웠다가 일어나는 프레임은 필요한 종만 제외한다. 고정 clip anchor를 사용하고 매 프레임 bbox 크기로 확대/축소하지 않는다. 얼굴형만 center origin, 나머지는 물리 발 기준이다. authored 꼬리·웅크림·hop의 모양 차이는 남긴다.

활동성 presets와 기존 시작4종/무제한 생성/한글명은 그대로다. Rest/Sleep은 시각 표현이며 별도 자율Sleep 상태·확률을 추가하지 않았다. 임의 Zzz/이모지/안경/말풍선/소품 오버레이는 없다. 보조 효과 설정은 기존 Canvas땀방울·폭탄 보조효과와 향후 승인된 효과에 그대로 적용한다.

향후 개인용 파닥몬/테리어몬/치이카와/쿠리만쥬/우소우소와 캐릭터별 스킬(커비 전방 부채꼴 흡입 등)은 별도 자산·권리·설계 작업이며 이번에는 구현하지 않았다. 실제Windows의동적전환/DPI/발접촉은QA의수동항목을따른다.
