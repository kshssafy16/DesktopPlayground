# Phase 2-B 보완: 9종 스프라이트 품질 안정화 작업 계획

## 우선순위

**2-B-1. 인벤토리와 미리보기**

- `SPRITE_INVENTORY.md`와 실제 로컬 `assets/pets/*`를 대조하고, `pet.json`과 원본 WebP의 프레임 목록 및 현재 런타임 clip mapping을 파일/행/열 수준으로 작성한다.
- 기본 9종 각각에서 idle, walkLeft, walkRight, rest/sleep, drag, fall 사용 프레임을 확인한다. 없는 것은 명시적 fallback으로 기록한다.
- 얼굴냥 9행 3~4열의 안경/손가락, 황색냥 왼쪽 이동 아티팩트, 푸들의 입에 문 소품, 영업냥 소품·다른 캐릭터 등장 프레임을 특별히 표시한다.
- 캐릭터마다 2초 이상 반복되는 영상/캡처 프리뷰를 만들고 실제 앱 렌더 경로와 일치하게 한다. 결과 비교 후 진행한다.

**2-B-2. 공통 프로필 및 렌더 안정화**

- 기존 `petDefinitions`와 `local-pets.js` 구조를 재사용하는 최소 수정으로, 캐릭터별 클립/프레임/반전/렌더 기준점/폴백을 데이터화한다.
- 9행·11행의 공통 셀 크기 활용. 단 행 의미는 반드시 개별 확인한다. 기존 원본 ID/폴더명/저장 데이터는 그대로 둔다.
- 발/중심 기준과 상태별 크기를 보정하되 포즈 차이를 지우는 강제 bbox 스케일 통일은 금지한다. 스프라이트 위치·크기가 프레임마다 흔들리지 않는지 실제로 검증한다.
- `cat_face`는 원본 안경과 손가락 포함 프레임을 재생하지 않는다. 이전 코드의 임의 이모지, Zzz, 말풍선, 안경/소품 오버레이도 제거하거나 기본 비활성화하되, 기존 Tray의 보조 효과 On/Off 설정과 호환되게 한다.

**2-B-3. 품질 수정과 회귀**

- 왼쪽 걷기 손상처럼 코드 미러링으로 해결되는 경우 원본 WebP는 유지한다. 파일 자체를 수정해야 한다면 왜 필요한지 명확한 재현과 개별 백업을 먼저 만든다.
- 모든 9종의 시각적 클립 시퀀스, 좌우, 반복, clip 전환, 추락/잡힘/착지와 DPI를 점검한다.
- 기존 자동 테스트(`pet-expression`, `autonomy`, `grab-throw`, `smoke`, `local-pets`)와 JS syntax, `git diff --check` 통과.
- `docs/v1.1/SPRITE_INVENTORY.md`와 진행 기록, QA에 실제로 확정된 매핑·수정·예외를 반영한다.

## 이번 단계에서 하지 않을 것

- 동작 품질을 핑계로 Sprite 전체 AI 재생성 금지.
- 임의 이모지/안경/장식/말풍선 추가 금지.
- 물리 상수, 기존 활동성, 4종 시작 펫, 펫 무제한 생성, 블랙홀 흡수 정책, 그리기, 구조물, 새 총/망치 구현 변경 금지.
- Import UI와 새로운 파일 확장자 전면 지원은 별도 단계.
- `v1.0.0` 태그, 원격 main, 기존 릴리스 ZIP 수정 금지. 이번에는 build/commit/push 하지 않음.

## 완료 기준

1. 9종에 대해 **의미가 확인된** 클립 이름, 사용 행/열/프레임, fallback이 기록됨.
2. 불필요한 소품이나 안경 프레임이 자동 재생되지 않음.
3. 대기, 보행, 잡힘, 던짐, 착지 상태에서 캐릭터가 갑자기 커지거나 위치가 튀는 현상이 유의미하게 개선됨.
4. 자동 검증 통과 + 실제 Windows에서 확인할 목록이 명시됨.
5. 코드는 향후 신규 펫 등록에 재사용 가능한 구조를 가짐. 단 과도한 플러그인 시스템은 도입하지 않음.

## 2026-10-13 실행 결과와 최신 범위

- 2-B-1/2/3의 자동·정적 보완 완료. 9개 원본 hash 일치, 캐릭터별9상태 매핑과 의미/fallback 확정, definition.animation과 공통 렌더러, 비연속 frames/frameMs/비반복/중심·발anchor 구현. 원본/ID/폴더/설정/목록/생성정책 보존.
- 얼굴냥 원본8행(0-based)2/3열 안경·손가락과 치아행은 사용하지 않음. 푸들 소품 이동/영업냥 분절·다른캐릭터·전복책상/과장행 제외. 황색냥 정상1행 반전 유지. 생성 Zzz 제거.

- 3.2초32장 native Pet.draw 반복·전환 preview와1x/2x 검사 생성/정적 비교. 실제Windows 동적/DPI/마우스·장시간 성능 QA는 별도다.
- 영업냥의 실제보행/공중과 푸들의 소품없는 측면보행은 원본 부족으로 fallback이며, 새 에셋 제작은 미진행이다. import/신규펫/도구/구조물/툴바/build/commit/push도 미진행이다.
